Installer AutoDeal comme une application

  • iPhone : ouvrez ce site dans Safari → bouton Partager → Sur l'écran d'accueil. AutoDeal s'ouvre ensuite en plein écran avec sa propre icône.
  • Android : Chrome → menu ⋮ → Installer l'application.
  • Ordinateur : Chrome ou Edge → icône d'installation dans la barre d'adresse.

Extension navigateur « AutoDeal Capture »

Sur une annonce Leboncoin ou un lot Alcopa (ou VPauto, Domaine, BCA, La Centrale) que vous consultez, un clic sur l'extension l'envoie ici et l'analyse aussitôt. L'extension ne lit que la page affichée, uniquement à votre demande.

  1. Téléchargez l'extension et décompressez-la.
  2. Dans Chrome, ouvrez chrome://extensions, activez le Mode développeur, puis « Charger l'extension non empaquetée » et choisissez le dossier autodeal-capture.
  3. Créez un jeton ci-dessous, puis collez-le avec l'adresse de ce site ({{ request_base }}) dans les réglages de l'extension.
Sur iPhone : le raccourci « AutoDeal » (bouton Partager de Safari)

Prérequis : site en ligne en https, et dans Réglages → Apps → Raccourcis → Avancé, activer « Autoriser l'exécution de scripts ».

  1. App Raccourcis → + → nommez-le « AutoDeal ». Dans ses réglages (ⓘ), activez Afficher dans la feuille de partage et ne gardez que Pages web Safari.
  2. Ajoutez l'action Exécuter JavaScript sur une page web et remplacez le code par :
  3. Ajoutez Obtenir le contenu de l'URL : URL
    Méthode POST · En-têtes : Authorization = Bearer suivi d'un espace et de votre jeton · Corps de la requête : Fichier → Résultat JavaScript.
  4. Ajoutez Obtenir la valeur du dictionnaire : clé resume, dans Contenu de l'URL.
  5. Ajoutez Afficher le résultat avec Valeur du dictionnaire. (Facultatif : une 2ᵉ valeur lien + Ouvrir les URL pour ouvrir la fiche.)

Utilisation : ouvrez l'annonce dans Safari (depuis l'app Leboncoin : Partager → Ouvrir dans Safari), puis Partager → AutoDeal.
