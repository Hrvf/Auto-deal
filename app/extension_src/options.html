AutoDeal Capture

Reliez l'extension à votre site AutoDeal. Le jeton se crée dans AutoDeal → Paramètres → Extension navigateur.

Utilisation

  1. Ouvrez une annonce Leboncoin ou un lot Alcopa (ou VPauto, Domaine, BCA, La Centrale).
  2. Cliquez sur l'icône AutoDeal dans la barre de Chrome, puis sur « Analyser ce véhicule ».
  3. La note, la marge et l'enchère maximale s'affichent ; la fiche complète est dans AutoDeal.

L'extension ne lit que la page affichée, uniquement quand vous cliquez. Elle ne navigue jamais seule sur les sites.
